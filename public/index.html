Sumber data: tije.info — aplikasi independen, bukan dashboard resmi PT Transportasi Jakarta. Feed: https://api.tije.info/buses (SSE / EventSource) (tanpa filter untuk semua rute), dengan format snapshot dan delta yang digunakan aplikasi sumber. Data posisi, waktu aktif, dan ketersediaan tergantung server. Peta dasar: © OpenStreetMap dan OpenFreeMap. Hanya bus dengan koordinat yang valid yang dapat dipetakan. Dashboard memakai EventSource dengan event snapshot/delta. Koneksi ke sumber pihak ketiga hanya tersedia jika server sumber mengizinkan. Gunakan Netlify melalui Git/CLI agar proxy satu domain ikut aktif; file lokal tidak dapat menjalankan proxy tersebut. Saat dibuka dari pratinjau WhatsApp JavaScript dapat tidak berjalan; gunakan Chrome/Safari atau website HTTPS.
